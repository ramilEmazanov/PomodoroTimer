# Pomodoro Timer

Приложение для macOS с таймером, задачами, проектами и историей сессий.

- **Таймер:** задавайте длительность, запускайте отсчёт, ставьте его на паузу, продолжайте или сбрасывайте. Последние использованные длительности доступны для повторного запуска.
- **Задачи:** создавайте и редактируйте задачи, добавляйте подзадачи, сроки и заметки, отмечайте важные и выполненные задачи. Добавляйте выбранные задачи в My Day на главном экране.
- **Проекты:** объединяйте задачи в проекты и просматривайте затраченное на каждый проект время.
- **Учёт времени:** запускайте таймер для конкретной задачи или без привязки. Время сессии учитывается у задачи и проекта; паузы исключаются, а при сбросе сохраняется фактически отработанное время.
- **Статистика:** просматривайте историю завершённых и прерванных сессий, график времени по дням, неделям, месяцам и годам, количество выполненных задач.
- **Настройки:** выбирайте тему и масштаб интерфейса.

Данные хранятся локально и доступны без интернета. Задачи, проекты, история, настройки и активный таймер сохраняются между запусками приложения.
