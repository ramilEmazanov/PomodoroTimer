# Приложение Pomodoro Timer

## Типичный пользователь

Pomodoro Timer — для человека, который хочет осознанно управлять рабочим временем, лучше фокусироваться на задачах и видеть статистику своей продуктивности. Это может быть специалист, фрилансер или студент, который самостоятельно планирует свою работу.

В течение дня он переключается между задачами, отвлекается и не всегда понимает, сколько времени уходит на работу. Ему нужен простой способ выделить время на конкретную задачу, сосредоточиться на ней и затем оценить затраченные усилия.

Основные потребности пользователя:

- **Контролировать рабочее время:** задавать длительность рабочих сессий и отслеживать время, потраченное на задачи.
- **Лучше фокусироваться:** работать над одной задачей в течение выбранного интервала.
- **Видеть свою продуктивность:** просматривать историю сессий и недельную статистику, замечать изменения в рабочем ритме.
- **Точнее планировать нагрузку:** сравнивать затраты времени на задачи и учитывать этот опыт при дальнейшем планировании.

Для пользователя результат — понятная картина того, куда уходит рабочее время, и более устойчивый ритм сосредоточенной работы. Статистика сессий помогает оценить затраченное время; качество и результат выполненной работы пользователь оценивает сам.

## Планируемые возможности

1. Установка таймера на заданное время
2. Таймер можно устанавливать на конкретную задачу
3. Хранятся логи таймеров, собирается статистика по неделям
4. Хранятся логи задач, время выполнения

## Текущая версия

Интерактивный прототип на React, TypeScript и Vite, созданный в Figma Make. Реализованы настройка таймера, отсчёт, пауза, продолжение и сброс с подтверждением. Главная показывает демонстрационные данные; статистика и настройки представлены заглушками. История сессий и сохранение данных пока не реализованы.

## Локальный запуск

Требуются Node.js 22.12+ и pnpm.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

Приложение доступно по адресу http://localhost:8443. Если порт занят, Vite укажет другой адрес в терминале.

```bash
pnpm typecheck # проверка типов
pnpm build     # сборка в dist/
pnpm preview   # просмотр сборки
pnpm format    # форматирование проекта
```

## Структура проекта

```text
src/
  components/  — общие элементы интерфейса и диалог сброса
  pages/       — главная, таймер и заглушки разделов
  utils/       — форматирование времени
  App.tsx      — состояние таймера и переключение разделов
  types.ts     — общие типы
  main.tsx     — точка входа React
  styles/      — стили приложения
config/        — конфигурация Vite
task.md        — требования учебного задания
public/        — статические ресурсы
submission/    — продуктовый сценарий и описание создания макета
```

Конфигурация Vite находится в `config/`. В корне остаются HTML, конфигурация TypeScript и файлы зависимостей, необходимые инструментам разработки. Локальные навыки агентов, настройки IDE, зависимости и результаты сборки исключены через `.gitignore`.

## Клиентские тесты

```bash
pnpm test
```

Vitest + React Testing Library проверяют защиту от повторного запуска: двойной клик Start, удержание Enter и попытки запустить Recents во время отсчёта и паузы. Проверяется видимое оставшееся время и отсутствие второго запуска часов. Время в тестах управляется виртуальными часами, реальные React-компоненты и логика таймера не подменяются.

Тесты созданы с помощью Codex по критерию № 7 из `task.md`. В приложении нет API и асинхронной отправки формы: эти проверки относятся к локальному таймеру и не подтверждают отсутствие повторного HTTP-запроса во время ожидания сервера.
