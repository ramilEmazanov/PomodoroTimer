# Focus for macOS

Нативный Pomodoro Timer на Swift и SwiftUI с локальным SQLite-хранилищем. Веб-версия в `src/` сохранена как образец.

## Требования и запуск

- macOS 14 или новее.
- Xcode 26 со Swift 6.2 или новее; выбранный Xcode в `xcode-select`.
- Сторонние зависимости не требуются.

Откройте `macOS/Package.swift` в Xcode, выберите схему **Focus**, назначение **My Mac** и нажмите Run (⌘R).

Для сборки самостоятельного приложения из корня репозитория:

```bash
bash macOS/scripts/build-app.sh
open macOS/build/Focus.app
```

Готовое `Focus.app` можно перенести в «Программы». Скрипт использует локальную ad-hoc подпись; аккаунт разработчика и публикация не нужны для этой сборки на своём Mac. Сборка предназначена для архитектуры текущего Mac.

Для быстрой отладочной сборки:

```bash
bash macOS/scripts/build-app.sh debug
```

## Возможности

- Реальный таймер: выбор длительности, ручной ввод, запуск, пауза, продолжение и сброс.
- Сохранение активной сессии: после перезапуска таймер продолжится, а истёкшая сессия попадёт в историю один раз.
- Таймер идёт во время сна Mac и при закрытом приложении; чтобы остановить учёт, нажмите Pause. Уведомления в закрытом приложении пока не реализованы.
- Паузы исключаются из учёта времени. Сброс сохраняет фактически отработанное время как прерванную сессию.
- Home: фактическое время за день и текущую календарную неделю, количество завершённых сегодня сессий, последние записи.
- Statistics: график за 7 или 30 дней и история завершённых и прерванных сессий с постраничной загрузкой.
- Время распределяется по календарным дням в текущем часовом поясе, даже если сессия пересекла полночь. Количество завершений относится к дню завершения.
- Tasks: создание и редактирование задач, подзадачи с отметками выполнения, дедлайн по дате, заметка и важность. Фильтры и сортировка.
- Projects: проекты с задачами и подзадачами, количество активных и завершённых задач, суммарное время фокусировки.
- Таймер можно назначить задаче: время учитывается у задачи и у проекта, к которому она относилась при запуске сессии.
- Recents, проекты, задачи и выбранная тема сохраняются между запусками.
- Settings: тема и сведения о локальном хранении.

Демонстрационные метрики и меню Prototype preview удалены. Облачная синхронизация пока не реализована.

## Задачи

Откройте Tasks в боковой панели. Введите название в поле Add a task и нажмите Enter или Add. Кнопка + и ⌘N переводят фокус в это поле. Выберите задачу, чтобы открыть её детали справа. При узком окне детали открываются отдельной панелью.

Название задачи и подзадач редактируется прямо в деталях. Next step добавляет подзадачу по Enter. Круглые отметки переключают выполнение; завершение родительской задачи не меняет отметки её шагов. Add due date добавляет срок, календарное поле позволяет изменить его, кнопка × — убрать. Дата считается просроченной со следующего дня в текущем часовом поясе. Звёздочка отмечает важные задачи. Заметка и все изменения сохраняются автоматически. Удаление задачи с подзадачами и заметкой требует подтверждения.

При ошибке записи изменения задач остаются в памяти и помечаются как несохранённые. Нажмите Retry storage до закрытия приложения. Существующая база обновляется до версии 3 с сохранением таймеров и истории; возвращаться к старой версии приложения с этой базой не следует.

## Проекты и учёт времени

Откройте Projects слева, введите имя в New project и нажмите Enter или Add project. Внутри проекта создавайте задачи с подзадачами, сроком и заметкой. Меню ⋯ позволяет переименовать или удалить проект; при удалении его задачи остаются в Tasks без проекта. В деталях любой задачи поле Project позволяет назначить или изменить проект.

Нажмите ▶ у задачи или Set timer for this task в её деталях, выберите длительность и запустите таймер. Также можно выбрать задачу в поле Task на экране Timer или оставить No task. У уже запущенной сессии назначение фиксировано до завершения или сброса. Паузы не учитываются, при сбросе записывается фактически отработанное время. Время задачи и проекта включает текущую сессию и сохраняется после перезапуска. Перенос задачи в другой проект влияет на будущие сессии; прошлое время остаётся у исходного проекта. Удаление задачи не удаляет её сессии из истории и времени проекта. История хранит название задачи и проекта на момент запуска сессии.

## Хранение

Приложение работает офлайн. База SQLite находится здесь:

```text
~/Library/Application Support/local.pomodoro.Focus/focus.sqlite
```

При запуске из другого bundle используется его идентификатор; при запуске Swift-пакета без bundle — путь выше. SQLite предоставляется macOS, сторонних пакетов нет. Активная сессия, задачи с подзадачами, последние длительности и тема хранятся отдельно от истории сессий. Записи истории содержат фактические интервалы фокусировки без пауз. Завершение сессии и очистка активного таймера выполняются в одной транзакции.

Для резервного копирования полностью закройте Focus и скопируйте папку `local.pomodoro.Focus` целиком, включая SQLite-файлы `-wal` и `-shm`, если они присутствуют. Ошибки чтения и записи отображаются в приложении; при ошибке изменения не выдаются за сохранённые. Повреждённая база не заменяется пустой автоматически.

## Проверки

Из папки `macOS/`:

```bash
swift build
swift test
```

Тесты используют временные SQLite-базы и управляемые часы. Проверяются паузы, восстановление после перезапуска и сна, отсутствие двойного учёта, частичные сессии, переход через полночь, ошибки хранилища и сохранение данных на диске. Для Tasks проверяются создание, редактирование, удаление, подзадачи, сроки, восстановление после ошибок записи и обновление базы версии 1 без потери данных.

Форматирование из корня репозитория:

```bash
swift format format --in-place --recursive macOS/Sources macOS/Tests macOS/Package.swift
```

## Структура

- `Sources/Focus/FocusApp.swift` — точка входа и состояние приложения.
- `Sources/Focus/WorkspaceView.swift` — навигация, тема, ошибки хранения и диалог сброса.
- `Sources/Focus/InterfaceState.swift` — управление таймером и сохранённым состоянием.
- `Sources/Focus/Session.swift` — сессии, интервалы и подсчёт статистики.
- `Sources/Focus/FocusStore.swift` — локальное SQLite-хранилище.
- `Sources/Focus/HomeView.swift` — сводка и история сессий.
- `Sources/Focus/StatisticsView.swift` — график и история за выбранный период.
- `Sources/Focus/TimersView.swift` — интерфейс таймера и Recents.
- `Sources/Focus/FocusTask.swift` — модель задач, подзадач и сортировка.
- `Sources/Focus/ProjectsView.swift` — проекты и их задачи.
- `Sources/Focus/TasksView.swift` — список, фильтры и создание задач.
- `Sources/Focus/TaskDetailView.swift` — редактирование задачи, шагов, дедлайна и заметки.
- `Sources/Focus/DurationWheel.swift` — колесо длительности.
- `Sources/Focus/Components.swift` — цвета и общие элементы.
- `Tests/FocusTests/` — проверки бэкенда.
- `scripts/build-app.sh` — сборка локального `.app`.
