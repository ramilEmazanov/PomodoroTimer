# Focus for macOS

Нативный Pomodoro Timer на Swift и SwiftUI с локальным SQLite-хранилищем. Веб-версия в `src/` сохранена как образец.

## Требования и запуск

- macOS 14 или новее.
- Xcode 26 со Swift 6.2 или новее; выбранный Xcode в `xcode-select`.
- Сторонние зависимости не требуются.

Откройте `macOS/Package.swift` в Xcode, выберите схему **Focus**, назначение **My Mac** и нажмите Run (⌘R).

Для сборки самостоятельного приложения из корня репозитория:

```bash
bash macOS/scripts/build-app.sh
open macOS/build/Focus.app
```

Готовое `Focus.app` можно перенести в «Программы». Скрипт использует локальную ad-hoc подпись; аккаунт разработчика и публикация не нужны для этой сборки на своём Mac. Сборка предназначена для архитектуры текущего Mac.

Для быстрой отладочной сборки:

```bash
bash macOS/scripts/build-app.sh debug
```

## Возможности

- Реальный таймер: выбор длительности, ручной ввод, запуск, пауза, продолжение и сброс.
- Сохранение активной сессии: после перезапуска таймер продолжится, а истёкшая сессия попадёт в историю один раз.
- Таймер идёт во время сна Mac и при закрытом приложении; чтобы остановить учёт, нажмите Pause. Уведомления в закрытом приложении пока не реализованы.
- Паузы исключаются из учёта времени. Сброс сохраняет фактически отработанное время как прерванную сессию.
- Home: фактическое время за день и текущую календарную неделю, количество завершённых сегодня сессий, последние записи.
- Statistics: график за 7 или 30 дней и история завершённых и прерванных сессий с постраничной загрузкой.
- Время распределяется по календарным дням в текущем часовом поясе, даже если сессия пересекла полночь. Количество завершений относится к дню завершения.
- Recents и выбранная тема сохраняются между запусками.
- Settings: тема и сведения о локальном хранении.

Демонстрационные метрики, задачи и меню Prototype preview удалены. Задачи и облачная синхронизация пока не реализованы.

## Хранение

Приложение работает офлайн. База SQLite находится здесь:

```text
~/Library/Application Support/local.pomodoro.Focus/focus.sqlite
```

При запуске из другого bundle используется его идентификатор; при запуске Swift-пакета без bundle — путь выше. SQLite предоставляется macOS, сторонних пакетов нет. Активная сессия, последние длительности и тема хранятся отдельно от истории сессий. Записи истории содержат фактические интервалы фокусировки без пауз. Завершение сессии и очистка активного таймера выполняются в одной транзакции.

Для резервного копирования полностью закройте Focus и скопируйте папку `local.pomodoro.Focus` целиком, включая SQLite-файлы `-wal` и `-shm`, если они присутствуют. Ошибки чтения и записи отображаются в приложении; при ошибке изменения не выдаются за сохранённые. Повреждённая база не заменяется пустой автоматически.

## Проверки

Из папки `macOS/`:

```bash
swift build
swift test
```

Тесты используют временные SQLite-базы и управляемые часы. Проверяются паузы, восстановление после перезапуска и сна, отсутствие двойного учёта, частичные сессии, переход через полночь, ошибки хранилища и сохранение данных на диске.

Форматирование из корня репозитория:

```bash
swift format format --in-place --recursive macOS/Sources macOS/Tests macOS/Package.swift
```

## Структура

- `Sources/Focus/FocusApp.swift` — точка входа и состояние приложения.
- `Sources/Focus/WorkspaceView.swift` — навигация, тема, ошибки хранения и диалог сброса.
- `Sources/Focus/InterfaceState.swift` — управление таймером и сохранённым состоянием.
- `Sources/Focus/Session.swift` — сессии, интервалы и подсчёт статистики.
- `Sources/Focus/FocusStore.swift` — локальное SQLite-хранилище.
- `Sources/Focus/HomeView.swift` — сводка и история сессий.
- `Sources/Focus/StatisticsView.swift` — график и история за выбранный период.
- `Sources/Focus/TimersView.swift` — интерфейс таймера и Recents.
- `Sources/Focus/DurationWheel.swift` — колесо длительности.
- `Sources/Focus/Components.swift` — цвета и общие элементы.
- `Tests/FocusTests/` — проверки бэкенда.
- `scripts/build-app.sh` — сборка локального `.app`.
