## Инструмент создания

Для создания макета приложения Pomodoro Timer использовалась **Figma Make**. Первоначальный вариант был создан с помощью текстового промпта, после чего состав показателей на главной странице был скорректирован.

## Использованный промпт
```
Создай интерактивный прототип приложения для фокусировки и управления таймером. Все тексты интерфейса — на русском языке.

ВИЗУАЛЬНАЯ ОСНОВА

Референс:
https://www.figma.com/community/file/1651309434229735362/macos-27

Приложение должно напоминать качественное нативное приложение Apple для macOS:
— светлая тема;
— спокойная нейтральная палитра и один синий акцент;
— чёткая иерархия текста и свободное пространство;
— деликатные тени и тонкие разделители;
— умеренная полупрозрачность боковой панели, если она соответствует референсу;
— простые контурные иконки одного стиля;
— крупные моноширинные по ширине цифры таймера, чтобы отсчёт не сдвигал интерфейс.

Сохраняй хорошую читаемость. Основную область с таймером оставь визуально спокойной. Не добавляй декоративные иллюстрации и лишние функции.

КОМПОНОВКА

Основной размер — desktop 1440 × 900.
Слева постоянная панель навигации:
1. Главная.
2. Установить таймер.
3. Статистика.
4. Настройки.

Активный раздел должен быть явно выделен.
Состояния настройки, отсчёта, паузы и завершения используй как состояния одного экрана с неизменной компоновкой.

ГЛАВНАЯ

Покажи:
— приветствие;
— сегодняшнюю дату;
— краткую статистику активности;
— задачи на сегодня.

Для наполненного состояния используй демонстрационные данные.
Также подготовь пустое состояние: статистика ещё не накоплена, задач на сегодня нет. Добавь понятное приглашение запустить первую сессию.

Состав показателей статистики — предварительное дизайнерское предложение, а не окончательное продуктовое требование.

НАСТРОЙКА ТАЙМЕРА

Покажи подписанное поле «Длительность, мин» и кнопку «Запустить».
Допускаются только целые числа от 1 до 1440 включительно.
Под полем укажи допустимый диапазон.

Для демонстрации можно подставить 25 минут. Это предварительное значение, которое ещё предстоит согласовать.

Пустое поле, дробное число, 0, отрицательное число и значение больше 1440 не позволяют запустить таймер.
При некорректном вводе показывай рядом с полем:
«Введите целое число от 1 до 1440 минут».

РАБОТАЮЩИЙ ТАЙМЕР

После запуска:
— показывай реальный обратный отсчёт в формате ЧЧ:ММ:СС;
— сделай оставшееся время главным визуальным элементом;
— показывай кнопки «Пауза» и «Сбросить»;
— не позволяй менять длительность во время текущей сессии.

Можно использовать тонкое кольцо прогресса, если оно гармонирует с прикреплённым UI-китом.
Значение времени никогда не должно становиться отрицательным.

ПАУЗА

Кнопка «Пауза» останавливает отсчёт с сохранением оставшегося времени.
Покажи статус «На паузе».
Кнопка «Пауза» заменяется на «Продолжить».
Кнопка «Сбросить» остаётся доступной.
«Продолжить» возобновляет отсчёт с сохранённого значения.

ПОДТВЕРЖДЕНИЕ СБРОСА

Сброс доступен во время отсчёта и на паузе.
При нажатии открывай модальный диалог в стиле прикреплённого UI-кита:

Заголовок: «Сбросить таймер?»
Текст: «Прогресс текущей сессии будет потерян».
Кнопки: «Отмена» и «Сбросить».

Подтверждение прекращает текущую сессию и возвращает к настройке с ранее выбранной длительностью. Новый отсчёт автоматически не запускается.

Отмена сохраняет предыдущее состояние:
— работающий таймер продолжает отсчёт;
— приостановленный остаётся на паузе.

Открытие диалога само по себе не ставит таймер на паузу.
Если время заканчивается при открытом диалоге, закрой диалог и покажи завершение сессии.

ЗАВЕРШЕНИЕ

Останови отсчёт на 00:00:00.
Покажи сообщение «Время вышло».
Добавь кнопку «Настроить новый таймер», возвращающую к настройке.

ГРАНИЦЫ ПРОТОТИПА

Главный сценарий — одна сессия таймера.
Не добавляй автоматические перерывы, циклы Pomodoro, авторизацию, звук или системные уведомления.
Разделы «Статистика» и «Настройки» оставь простыми заглушками в общем стиле: их подробное поведение пока не определено.

ДОСТУПНОСТЬ

Поля имеют видимые подписи.
Кнопки и поле доступны с клавиатуры и имеют видимый фокус.
Статусы и ошибки передаются текстом, а не только цветом.
У диалога есть понятные действия подтверждения и отмены.

РЕЗУЛЬТАТ

Собери связанный интерактивный прототип:
главная → настройка → отсчёт → пауза → продолжение;
отсчёт или пауза → подтверждение сброса → отмена или сброс;
отсчёт → завершение → новая настройка.

Подготовь все состояния для просмотра:
1. Главная с данными.
2. Главная без данных.
3. Настройка таймера.
4. Ошибка ввода.
5. Работающий таймер.
6. Пауза.
7. Диалог сброса.
8. Завершённый таймер.

Придерживайся прикреплённого macOS-референса во всех состояниях.
```

## Изменения главной страницы

В первоначальном варианте на главной странице отображались три карточки статистики:

- часы фокуса за сегодня;
- количество завершённых сессий;
- серия дней с фокусом (стрик).

После доработки состав карточек изменился:

- часы за сегодня;
- часы за неделю;
- количество завершённых сессий.

Карточка «Часы за неделю» заменила серию дней с фокусом. Такой набор показателей помогает пользователю оценивать затраченное рабочее время за день и неделю и видеть количество завершённых сессий.
